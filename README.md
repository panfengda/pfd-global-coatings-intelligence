# PFD Coating Intelligence

全球涂料企业与产业链信息目录（静态网站）。

## 部署到 GitHub Pages
1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment → Source** 选择 **GitHub Actions**。
3. 工作流会在推送到 main 后自动部署。也可在 **Actions** 页面手动运行 “Deploy static site to GitHub Pages”。
4. 网站地址： https://panfengda.github.io/pfd-global-coatings-intelligence/

## 当前版本范围
- 全球企业样本名录、地区/业务筛选、官网跳转
- 企业榜单展示框架
- 技术方向和产业链分类
- 响应式布局，支持手机浏览

## 数据说明
当前是初始样本目录，不代表完整全球企业名录。未填入未经统一口径核验的销售额或名次。企业信息应逐条核对官网、年报及行业榜单后再用于正式分析。
